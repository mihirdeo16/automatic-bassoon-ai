### Agents 
This repo contain initial code to get started with agent. This is inspired from google's [Multi-Agent Systems Hackathon](https://googlecloudmultiagents.devpost.com/)
Here are some helpful links to get started:
- [Get API Key](https://aistudio.google.com/)
- [Resources](https://googlecloudmultiagents.devpost.com/resources)
- [ADK Documentation](https://google.github.io/adk-docs/)
- [Google Cloud](https://console.cloud.google.com/)

To get started follow these steps:
1. Read/Go through the [adk-docs/get-started](https://google.github.io/adk-docs/get-started/installation/)
2. Install dependencies using `pip install -r requirements.txt`
3. Create `.ENV` file inside the project directory `tiny-ai-agent` and put API key in ENV file.
4. Run the agent using `adk tiny-ai-agent`.
